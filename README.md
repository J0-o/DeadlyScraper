# DeadlyScraper

A command-line tool for reading metadata and downloading from Deadly Stream.

## Requirements

- .NET 8 SDK to build from source

## Usage

```text
DeadlyScraper.Cli <deadlystream file page url> [options]

Options:
  --help                         Show help.
  --version <version label>      Select the first matching historical version.
  --file <exact file name>       Download only the first matching file.
  --download <directory>         Download to the specified directory.
```
